# BOTTONS PRO 5K

Landing page Next.js pronta para GitHub + Vercel, construída sobre a oferta de artes digitais para bottons e ímãs e adaptada para o mecanismo **biblioteca + curso + ferramentas**.

## Estrutura da oferta

- Biblioteca com **+5.000 artes** para bottons e ímãs.
- Artes editáveis no Canva.
- Quatro tamanhos principais: 3,2 cm, 3,8 cm, 4,4 cm e 5,8 cm.
- Plano Starter com pack reduzido.
- Plano Completo com biblioteca 5K, curso, calculadora, guia, bônus e atualizações.
- Curso Bottons do Zero.
- Calculadora interativa de precificação.
- Guia de Vendas e Nichos.
- Bônus: artes cristãs, gamer, profissões e material de criação com IA.
- Garantia configurada em 30 dias.

## Checkouts

`src/config/offer.ts`

Antes de publicar, confirme se os links pertencem à sua oferta.

## Rodar localmente

```bash
npm install
npm run dev
```

## Deploy na Vercel

1. Suba o conteúdo deste ZIP para a raiz do repositório GitHub.
2. Importe o repositório na Vercel.
3. Framework: Next.js.
4. Root Directory: `./`
5. Build command: `npm run build`

O projeto usa `output: 'export'` e imagens locais em `public/`.

## Observações

A página não inclui depoimentos inventados ou números de vendas fictícios. As artes e os elementos de terceiros devem ser usados conforme suas respectivas licenças. Resultados comerciais variam conforme produto, preço, execução e divulgação.
